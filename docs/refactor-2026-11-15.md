## ผลการปรับ

- ถอด `/api/community/review-queue`, selector ที่ใช้พิกัดจริง และ helpers ของ peer/star
  ที่ไม่มี caller แล้ว คงคิวขอทบทวน Trust ปัจจุบันและข้อมูล audit/migration เดิม
- Selection ของรายงานอ่าน snapshot ล่าสุดของโหมดนั้น ภาพต่ออายุผ่าน permission/time
  context เดิม พร้อมจำกัด retry ต่อ URL และป้องกัน response เก่าจากอีกบัญชี
- เพิ่ม station notification deep link โดยให้ request → report → station มีลำดับชัดเจน
- Publication ใช้ policy snapshot ต่อ operation; policy/registered bonus control
  ขัดข้องไม่ขวาง final OCR decision และไม่ให้สิทธิ์ gap-fill โดยเดา
- เก็บ extraction/context facts เดิมเพื่อ retry สร้าง evidence ที่ขาดหลัง policy ฟื้น
  โดยไม่ทำ OCR/moderation ซ้ำ ไม่สร้าง report/XP ซ้ำ ไม่มี schema ใหม่สำหรับ recovery queue
- แยก ReportForm lifecycle เป็น `useReportDraft`; UI คงฟอร์มเดิมและป้องกัน late response
  หลังออกจากหน้า/เปลี่ยนบัญชี แยก station timeline ออกจาก MapPageClient
- แยก XP เป็น stable facade, accounts/identity/leaderboard, rewards/claims/settlement
  และ runtime controls/demo state ซึ่งมีเจ้าของ state/lock เพียงแห่งเดียว
- แยก persistence ของ profiles/feed และ report media ออกจาก report queries;
  workflows ยังใช้ `supabase_client` facade เดิม
- จัด model contract barrel เป็น imports และ `__all__` ชุดเดียว; OpenAPI ที่คงอยู่เหมือนเดิม
- ลบ CSS 347 rules / 412 selector branches ที่ไม่มี caller รวมถึง dynamic marker checks
  แล้วจัดเป็น pages, map, refinements, flows โดยรักษาลำดับ cascade
- ปรับ README ให้ชี้ contribution-v3 และ Trust ปัจจุบัน

AST comparison ยืนยันว่า XP functions ที่ย้ายทั้ง 26 ฟังก์ชันมี logic เดิม
หลัง normalize การอ้างโมดูลใหม่ ส่วน persistence ที่ย้ายคง query เดิม
