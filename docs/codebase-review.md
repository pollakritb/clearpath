# ClearPath — หน้าที่ของไฟล์และผล system audit

บันทึก system audit ของ source วันที่ **17 พฤศจิกายน 2026** ก่อน release ต่อมาเจ้าของอนุญาต commit/push/deploy/apply migration แล้ว สถานะการนำขึ้นและหลักฐาน recovery/migrations ดู [execution record](runbooks/database-completion-progress-2026-11-15.md) ไม่ใช้รายงาน local audit นี้แทนการตรวจ production

## อ่านรายงานนี้อย่างไร

ตารางด้านล่างระบุไฟล์ของ project ทุกไฟล์แยกตามส่วนงาน: หน้าที่, ผู้เรียก/กลไกที่ใช้ และเหตุผลที่ไม่ควรตัดสินว่าเป็น dead code เพียงเพราะไม่มีปุ่มบนหน้าเว็บ กดชื่อไฟล์เพื่อเปิด source ได้ รายการรวมไฟล์ที่เพิ่มจากการ cleanup; ไฟล์ที่นำออกแล้วอยู่ใน [cleanup record](cleanup.md) และ external archive

ตรวจ inventory/เนื้อหา/imports/AST/contracts/CI/test discovery ครบไฟล์ และตรวจด้วยมือที่ privacy/authentication, Admin guards, coordinates, signed images, cron guards, configuration และจุดที่แก้ ไม่ได้อ้างว่า manual security audit ทุกบรรทัดหรือทดสอบ production services จริง

**ขอบเขตข้อมูลลับ:** ระบุชื่อ/หน้าที่ของ .env เท่านั้น ไม่อ่านค่ารหัสผ่านออกในรายงาน การ inventory dependency/build/.git ทุก file path เป็น metadata ใน private archive; ไม่อ้างว่าเราเขียนหรือ audit implementation ภายในทุก dependency

## ผล audit และสิ่งที่แก้

- พบและยืนยันด้วย failing regression ว่า Moderator ได้พิกัดจริงจาก `/api/admin/reports`; แก้ให้ต้องมี Admin role จึงเห็นพิกัดจริง Moderator ได้ stable public coordinates และไม่มี raw image/moderation metadata ที่อาจมี GPS แต่ยังดูภาพ ผล OCR และสถานะรายงานได้
- แสดง label `ตำแหน่งโดยประมาณ` และ precision จริงให้ response ที่ปกปิดพิกัด เพื่อไม่อ้างว่าเป็นพิกัดจริงหรือ ±0 เมตร
- เจ้าของยืนยัน hotspot **ทั่วประเทศไทยตาม runtime ปัจจุบัน**; ปรับ AGENTS.md ให้ตรงกับ runbook/runtime ไม่เปลี่ยนพฤติกรรมแผนที่
- แก้ setuptools package discovery ให้ค้นหาเฉพาะ backend/api และไม่รวม backend.tests ทำให้ `uv lock --check --offline` ผ่านโดยไม่เปลี่ยน dependency versions; กัน `*.egg-info/` ซึ่งเป็น generated metadata ออกจาก Git
- แก้ relative link ของแผนฐานข้อมูลที่ชี้ไปเอกสารซึ่งนำออกแล้ว ให้ชี้รายงานตารางปัจจุบัน
- เอา Ruff exception/coverage globs ที่อ้างไฟล์ซึ่งไม่มีแล้วออก โดยไม่ลด coverage thresholds
- แก้ npm format/format:check ให้ส่ง `"docs/**/*.md"` เป็น glob ถึง Prettier จึงตรวจ docs ทุกระดับจริง รวมรายงานนี้
- Cleanup ก่อนหน้ายัง local และคืนได้จาก archive; ไม่ลบ migration history/legacy settlement/audit retention ที่ระบบยังต้องใช้
