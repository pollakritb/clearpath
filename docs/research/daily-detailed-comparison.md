# เทียบข้อมูล CAMS/Open-Meteo กับ Air4Thai รายวัน — ชุดทดลอง 4 สถานี

> **อ่านก่อน:** ตารางนี้แสดงสองแหล่งข้อมูลข้างกันเพื่อดูความครบถ้วนและแนวโน้มเบื้องต้น **ไม่ใช่ผลวัดความแม่นยำ** และไม่มี MAE/Bias/เปอร์เซ็นต์แม่นยำ
> สร้างจากไฟล์ทดลอง 27 รอบ ณ 27/10 17:07 น. เวลาไทย; ข้อมูลต้นทางอยู่เฉพาะเครื่องและไม่ใช้ Production Supabase

ฉบับนี้เป็น snapshot สำหรับอ้างอิงใน GitHub; ไฟล์ JSON ต้นฉบับและ log ยังเก็บเฉพาะเครื่อง ไม่มีข้อมูลผู้ใช้หรือ secret ในรายงานนี้ แหล่งข้อมูล: [Open-Meteo/CAMS](https://open-meteo.com/en/docs/air-quality-api) และ [Air4Thai กรมควบคุมมลพิษ](https://air4thai.pcd.go.th/)

## วิธีอ่าน

- **CAMS:** ค่า PM2.5 ที่พยากรณ์ให้แต่ละชั่วโมง (หน่วย µg/m³) หากชั่วโมงเดียวกันมีหลาย snapshot เลือกรอบที่ **ดึงล่าสุดก่อนเวลาที่พยากรณ์ใช้ได้** เพียง 1 ค่า; ไม่ใช่เวลาออกรอบแบบจำลอง
- **Air4Thai:** ค่า `type=hr` ตามป้ายเวลาต้นทางที่เก็บได้ นับแต่ละสถานี-ชั่วโมงครั้งเดียว; คำว่า ‘เวลาตรงกัน’ หมายถึงป้ายเวลาเท่ากันเท่านั้น ยังไม่ยืนยันว่าค่าเฉลี่ย 1 ชั่วโมงครอบคลุมช่วงไหน
- **ช่วงค่า:** ต่ำสุด–สูงสุด (ค่ากลาง/median) ของ **ชั่วโมงที่มีข้อมูลในวันนั้น**; สองชุดอาจมีจำนวนชั่วโมงไม่เท่ากัน จึงห้ามลบค่ากลางหรือช่วงค่าเพื่ออ้างเป็นความคลาดเคลื่อน
- **ระยะถึง grid:** ระยะจากพิกัดสถานี Air4Thai ถึงศูนย์กลาง grid ที่ CAMS ตอบ เป็นค่าเดียวกันในทุกวันที่เก็บ ไม่ใช่ระยะครอบคลุมของแบบจำลองหรือคะแนนความแม่นยำ
- **วัน:** ใช้วันที่ตามเวลาไทยของ `valid_at` สำหรับ CAMS และของป้ายเวลาต้นทางสำหรับ Air4Thai ไม่ใช่วันที่กดดึง API; วันที่แรก/ท้ายอาจมีข้อมูลไม่ครบ 24 ชั่วโมง
- **ช่วงค่าจริงที่เก็บ:** การทดลองหยุดดึงข้อมูลในวันที่ 25 ต.ค. 2569; วันที่หลังจากนั้นอาจยังมีพยากรณ์ล่วงหน้า แต่ไม่มีค่าจริงในไฟล์ทดลอง **ไม่ใช่หลักฐานว่าสถานีหยุดทำงาน**
- ตารางรายชั่วโมงด้านล่างแสดงค่า Air4Thai ข้าง CAMS เฉพาะเมื่อ **ป้ายเวลาเท่ากัน**; ช่อง ‘—’ หมายถึงไม่พบป้ายค่า ไม่ใช่ค่าฝุ่น 0

1. CAMS Global เป็นแบบจำลองระดับพื้นที่ ไม่ใช่เครื่องวัดที่สถานี; ความละเอียดต้นทางประมาณ 0.4°/45 กม. และ 3 ชั่วโมง แม้ API ให้ค่ารายชั่วโมง [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api)
2. Air4Thai อธิบายว่ากราฟรายชั่วโมงเป็นค่าเฉลี่ย 1 ชั่วโมง แต่ยังต้องยืนยันว่า timestamp ของ `type=hr` หมายถึงต้นหรือปลายช่วงเฉลี่ย [คำอธิบายกรมควบคุมมลพิษ](https://epo08.pcd.go.th/th/news/detail/180206)
3. บางสถานีไม่มีป้ายค่าจริงก่อนสิ้นสุดชุดทดลอง ให้ตรวจความพร้อมของข้อมูลก่อนวิเคราะห์; ส่วนวันที่หลังหยุดเก็บไม่ใช่หลักฐานว่าสถานีหยุดทำงาน และรอบเก็บที่ขาดห้ามเติมย้อนหลังเป็น snapshot ณ เวลานั้น
4. เมื่อยืนยันนิยามเวลาแล้ว จึงจับคู่ชั่วโมงที่ถูกต้องและคำนวณ MAE/Bias แยกสถานีและ lead time พร้อมจำนวนชั่วโมงไม่ซ้ำ; จนถึงตอนนั้น **ผลความแม่นยำ = ยังไม่มีผลประเมิน**

ไฟล์ต้นฉบับของรายงานนี้สร้างซ้ำได้ด้วย `.venv/Scripts/python -m scripts.report_independent_cams_trial_daily` จาก root ของโปรเจกต์ และอยู่ใน `.forecast-validation/independent-four-station/` ซึ่งถูก `gitignore`; ไฟล์ใน `docs/research/` เป็น snapshot สำหรับเผยแพร่ ไม่ได้อัปเดตอัตโนมัติ
