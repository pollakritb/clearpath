# CAMS forecast field validation (prepared, not active)

The public forecast uses unadjusted Open-Meteo/CAMS Global PM2.5 for the requested station or area. It does not use Air4Thai readings to alter the forecast. The response carries the requested coordinates, provider grid-cell coordinates, UTC `fetched_at`, and per-point UTC `valid_at`. Clients render `valid_at` in the user's time zone. A 24-hour request returns consecutive future hourly slots only; a partial provider response is marked `external_provider_partial_horizon`, never filled with invented values.

The isolated `/api/cron/forecast-validation` collector is authenticated but **disabled by default** (`FORECAST_VALIDATION_ENABLED=false`) and is not registered with any Production scheduler. The migration `20261015_forecast_validation_evidence.sql` is not applied automatically. It creates private snapshot and reserved one-hour observation tables with no public RLS access. On a future six-hour schedule, the collector would choose station `103t` plus nine geographically spread stations, save the next 24 hourly provider values along with both coordinate pairs and timestamps, deduplicate by station/UTC collection slot/valid time, and retain at most 90 days. This is field-test evidence only; the public API never reads it. The observation table is intentionally empty until its source is verified.

Before enabling, verify the official Air4Thai **one-hour PM2.5** observation source, its averaging window and timestamp semantics, station mapping, completeness, data licence, and storage quota. The existing `pm25_readings`/Air4Thai headline value must **not** be treated as a one-hour truth set; it may be a rolling 24-hour value. Collect only explicitly labelled one-hour observations, align them to forecast `valid_at` in UTC, and reject forecasts fetched after the valid hour. The pure validation helpers can then report provisional MAE and signed bias for 1–6h and 7–24h, with sample count, missingness and station breakdown. Do not advertise accuracy, apply bias correction, or enable another model based on these provisional metrics alone. Field-test activation, migration application, and Production scheduling require a separate review.

Provider reference: [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api). CAMS Global grid spacing is approximately 45 km; hourly API values do not imply hourly native model resolution or point-specific accuracy.
