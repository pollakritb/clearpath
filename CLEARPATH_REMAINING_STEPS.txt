ขั้นที่ 1 — เตรียม Vercel Hobby และ GitHub Actions
======================================================================

ClearPath ใช้ Vercel Hobby ได้แล้ว โดย vercel.json ไม่มี Vercel cron และ workflow
.github/workflows/production-scheduler.yml จะเรียกงานที่ป้องกันด้วย CRON_SECRET
ทุกชั่วโมงแทน เพื่อลดจำนวน GitHub Actions runs และคง Air4Thai freshness รายชั่วโมง

[ ] ใช้ Vercel Hobby ได้ ไม่ต้องอัปเกรด Pro
[ ] หลังได้ Production URL ให้เพิ่ม GitHub Actions repository variable
    CLEARPATH_PRODUCTION_URL=https://<PRODUCTION_HOST> (ไม่มี slash ท้าย)
[ ] เพิ่ม GitHub Actions repository secret CRON_SECRET ให้ตรงกับ Vercel Production
[ ] ถ้า repository เป็น private ให้ตรวจ Actions Usage รายเดือน เพราะใช้โควตาฟรีร่วมกับ CI
[ ] ยอมรับว่า GitHub scheduled workflow อาจเริ่มช้ากว่าเวลาที่กำหนดเมื่อระบบโหลดสูง
[ ] เปิด MFA ให้ GitHub, Vercel, Supabase, OpenAI และบัญชีผู้ดูแล
[ ] แยก Supabase staging และ production คนละ project

ขั้นที่ 3 — ตั้ง Environment Variables ใน Vercel
======================================================================

ตั้ง Preview และ Production แยกกันผ่าน Vercel dashboard หรือ `vercel env add`
อย่าวาง secret ใน source code, terminal history, issue หรือ chat

ค่าที่ต้องมี:

[ ] APP_ENVIRONMENT=staging สำหรับ Preview / production สำหรับ Production
[ ] LOCAL_DEMO_MODE=false หรือไม่สร้างตัวแปรนี้เลย
[ ] RELEASE_SHA=<git commit sha>
[ ] SUPABASE_URL
[ ] SUPABASE_SERVICE_ROLE_KEY (server only ห้ามใช้ NEXT_PUBLIC_*)
[ ] NEXT_PUBLIC_SUPABASE_URL
[ ] NEXT_PUBLIC_SUPABASE_ANON_KEY
[ ] REPORT_IMAGE_BUCKET=report-images
[ ] CRON_SECRET สุ่มอย่างน้อย 32 ตัวอักษร
[ ] CAPTURE_SESSION_SECRET สุ่มอย่างน้อย 32 ตัวอักษรและห้ามซ้ำ CRON/Supabase key
[ ] CORS_ALLOWED_ORIGINS=https://<PREVIEW_OR_PRODUCTION_HOST> ไม่มี wildcard
[ ] OPENWEATHER_API_KEY เมื่อ OPENWEATHER_AIR_ENABLED=true
[ ] FIRMS_MAP_KEY หากต้องการ satellite hotspot จริง
[ ] OPENAI_API_KEY เมื่อ AUTOMATIC_REVIEW_ENABLED=true
[ ] COMMUNITY_FORECAST_SHADOW_ENABLED=false ตอน launch
[ ] ML_FORECAST_ENABLED=false
[ ] ML_FORECAST_SHADOW_ENABLED=false
[ ] ML_FORECAST_CANARY_PERCENTAGE=0
[ ] PUSH_ENABLED=false จนกว่าจะตั้ง VAPID และทดสอบ delivery จริง

หากยังไม่มี OPENAI_API_KEY ให้ตั้ง AUTOMATIC_REVIEW_ENABLED=false ระบบจะ fail
closed และเก็บเคสไม่ชัดเป็น pending ให้ Admin ตรวจ ห้ามเปิด auto-review โดยไม่มี OCR

Preflight ล่าสุดบนเครื่องนี้ยังไม่พร้อมเพราะ:

- APP_ENVIRONMENT ยังไม่ใช่ production
- NEXT_PUBLIC_SUPABASE_URL/ANON_KEY ยังไม่ครบ
- CAPTURE_SESSION_SECRET ยังไม่แยก
- AUTOMATIC_REVIEW_ENABLED=true แต่ OPENAI_API_KEY ไม่พร้อม
- เชื่อม Supabase ไม่ได้จาก DNS เครื่องนี้ ทำให้ตรวจ 28 tables ไม่สำเร็จ

หลังใส่ staging env ให้รันจน `ready: true`:

    .venv\Scripts\python -m scripts.production_preflight `
      --env-file .env.local --json --strict-features

[ ] หน้า /, /air, /report, /community ไม่มี horizontal overflow

======================================================================

ทำเมื่อ Preview, backup, privacy/security และ device acceptance ผ่านแล้วเท่านั้น:

    vercel deploy --prod
    .venv\Scripts\python -m scripts.verify_deployment `
      https://<PRODUCTION_HOST>
    vercel logs --environment production --level error --since 5m

ตรวจ GitHub > repository > Settings > Secrets and variables > Actions:

[ ] Variable CLEARPATH_PRODUCTION_URL เป็น HTTPS Production URL
[ ] Secret CRON_SECRET ตรงกับค่าใน Vercel Production
[ ] Actions > Production hourly scheduler > Run workflow สำเร็จ
[ ] Scheduled run ทำงานที่นาที 7 ของทุกชั่วโมงบน branch main
[ ] sync, alerts และ forecast-evaluation ได้ 2xx ทุกชั่วโมง
[ ] OpenWeather ได้ 2xx ทุก 8 ชั่วโมงและ Open-Meteo ได้ 2xx ทุก 12 ชั่วโมง
[ ] Vercel Settings > Cron Jobs ว่าง ซึ่งเป็นสถานะที่ถูกต้องสำหรับ Hobby
[ ] ไม่มี /api/cron/forecast-consensus
[ ] Air4Thai sync มี station/readings และ rejected diagnostics
[ ] Provider sync เก็บ snapshots โดยไม่ทำให้ค่าหลักหน้าเว็บถูกเฉลี่ยทับ
[ ] /api/ready = 200 และมี official station สดอย่างน้อยหนึ่งสถานี
